# Cheatsheet Format

Cheatsheets live in `$LEARNING_HOME/cheatsheets/<slug>.md`. They are the compressed residue of a session: designed for a 30-second revisit weeks later, not a re-read of the lesson. The conversation taught; this is what remains.

## Structure

```md
# <Tema>

<Definição de uma linha, apertada como verbete de glossário: o que É.>

## Esqueleto de derivação
1. <fundamental que o usuário já domina>
2. <logo, …>
3. <logo, …> → <o conceito, agora re-derivável>

## Trade-offs
| A favor | Contra | Quando dói |
| --- | --- | --- |

## Sintaxe / comandos
<Só se o tema tiver. Mínimo, anotado.>

## Armadilhas
- <modo de falha coberto na sessão, uma linha cada>

## Fontes
- [Docs oficiais](url) — quando recorrer.
- [Comunidade](url) — só se for genuinamente de alta reputação.

*Última sessão: YYYY-MM-DD · nível: <N>*
```

## Rules

- **Compression over completeness.** If a section has nothing decision-grade, cut the section. The chat holds the full lesson; the cheatsheet holds what is worth returning to.
- **The derivation skeleton is not optional.** It is what separates a cheatsheet from a manual page: the user re-derives instead of re-reading.
- **Same language as the session:** português do Brasil, termos técnicos em inglês.
- **Every citation is real.** A source that was not actually consulted does not go in.
